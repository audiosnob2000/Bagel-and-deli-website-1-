# Corner Bagel & Deli

A warm, single-page website for a neighborhood bagel and deli shop.

## Structure

- `index.html` — page markup (Home, Menu, About, Location & Hours)
- `css/style.css` — styling (light/dark aware, responsive)
- `js/script.js` — mobile nav toggle, footer year, scroll-reveal animations

## Running locally

No build step required — open `index.html` directly in a browser, or serve
the folder with any static file server, e.g.:

```
python3 -m http.server 8000
```

## Customizing

Swap in the real business name, address, phone number, hours, and menu
items directly in `index.html`.
