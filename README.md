# Miller Place Bagels & Deli

An editorial, photo-led website for Miller Place Bagels & Deli — a real
bagel and deli shop at 159 Route 25A, Miller Place, NY, open 5 AM daily.

## Structure

- `index.html` — page markup (Home/hero, Menu, About, Visit & Hours)
- `css/style.css` — styling (indigo-and-gold editorial system, responsive)
- `js/script.js` — mobile nav toggle, footer year, scroll-reveal animations
- `fonts/` — self-hosted Source Serif 4 and Manrope (woff2)
- `images/storefront.jpg` — the shop's real storefront photo, used as the home page hero

## Running locally

No build step required — open `index.html` directly in a browser, or serve
the folder with any static file server, e.g.:

```
python3 -m http.server 8000
```

## Content notes

Address, phone, and hours are the shop's real listed details. Menu items
and prices are representative (sourced from public listings) — swap in the
shop's actual current menu and prices when available.
